## 🌤️ 今日更新

**2026 年 11 月 27 日**

### 🍞 面包发霉｜整块丢弃，别只切掉霉点

面包出现霉点时，内部可能已经被菌丝侵入，肉眼看不到的部位也可能受污染。发现霉变就丢弃这块面包，避免切掉表面后继续吃。

来源 · [深圳市市场监督管理局](https://www.sz.gov.cn/xxgk/ztzl/tzxf/szsz/spaqjs/content/post_12584595.html)

### 💊 药片分服｜先确认说明书是否允许掰开

缓释片、控释片、肠溶片多数需要保持原有结构。服用前看说明书，明确要求整片吞服的就按要求服用，吞咽困难时请医生或药师帮助选择合适剂型。

来源 · [国家卫生健康委新闻发布会（国家疾控局转载）](https://www.ndcpa.gov.cn/jbkzzx/c100009/common/content/content_2097500968284753920.html)

### 🚿 燃气热水器｜通风与排烟都要留意

冬季使用燃气热水器时保持通风，确保燃烧废气能排到室外。留意烟管是否脱落、开裂，排烟口是否堵塞，发现异常请专业人员检修后再使用。

来源 · [苏州市住房和城乡建设局](https://zfcjj.suzhou.gov.cn/szszjj/rqzs/202212/444e6358f9954c28bea8a3b3f1b07d60.shtml)

### 🚗 气温下降｜出车前留意胎压报警

降温可能使轮胎气压降低。出发前看看仪表盘是否有胎压报警，发现异常及时检查，避免带着胎压不足的问题继续行驶。

来源 · [上海市人民政府（上海发布转载）](https://www.shanghai.gov.cn/nw17239/20261118/84a948aea2094937b59e76922510bf49.html)

### 📦 陌生快递｜先核对订单，再处理随附卡片

收到没有印象的快递，先通过购物平台或快递公司官方渠道核对。包裹里的“扫码领礼品”“做任务返现”卡片可能是诈骗入口，避免扫码填写个人信息或垫付资金。

来源 · [武汉市邮政管理局（湖北省邮政管理局发布）](https://hb.spb.gov.cn/hubsyzglj/c104613/c104616/202503/1b2e9cb8b67b4db1942cd3ae024086e0.shtml)
