## 🌤️ 今日更新

**2026 年 11 月 28 日**

### 🥚 选鸡蛋｜蛋壳颜色主要由品种决定

红壳、白壳或青壳，主要与产蛋鸡的遗传因素有关。蛋壳颜色与营养价值没有直接关系，选购时可以更关注新鲜度和保存条件。

来源 · [深圳市市场监督管理局](https://www.sz.gov.cn/szzt2010/zdlyzl/spypaq/aq/xfzs/content/post_7851158.html)

### 🏃 流感恢复｜症状刚减轻，先缓一缓高强度训练

流感急性期和恢复早期应避免高强度锻炼，恢复运动要循序渐进。运动时若出现胸闷、憋气或心悸，立即停止并及时就医。

来源 · [国家疾病预防控制局](https://www.ndcpa.gov.cn/jbkzzx/c100009/common/content/content_2125119025609871360.html)

### 🍲 自热食品｜发热包按说明加凉水

使用前先看包装说明，给发热包加凉水，保持盒盖出气孔畅通。加热时放在隔热垫上，手和脸避开蒸汽，发热包漏粉时停止使用。

来源 · [永州市市场监督管理局](https://amr.yzcity.gov.cn/amr/0310/202210/37716284880747ffac4848b74fd3b394.shtml)

### 🚗 儿童安全座椅｜系肩带前脱下厚外套

厚外套被压缩后，原先看似系紧的肩带可能留下空隙。孩子坐入安全座椅时脱下厚外套，再按座椅说明调整肩带，使其贴合身体。

来源 · [湖南省应急管理厅](https://yjt.hunan.gov.cn/yjt/tszt/aqzs/201510/t20151001_3113692.html)

### 💻 离开座位｜按 Win + L 锁定电脑

在 Windows 上按 Win + L 就能锁定电脑。办公或在公共场所使用电脑时，临时离开前按一下，回来后再解锁继续使用。

来源 · [微软支持](https://support.microsoft.com/zh-cn/accessibility/windows/keyboard-shortcuts-in-windows)
