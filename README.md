## 🌤️ 今日更新

**2026 年 11 月 22 日**

### 🥫 食品开封｜按包装上的开封后要求保存

预包装食品标注的保质期，通常以包装完好、按要求贮存为前提。开封后留意“需冷藏”“尽快食用”等说明，可以在包装上记下开封日期。

来源 · [哈密市市场监督管理局](https://www.hami.gov.cn/hami/c120182/202505/145fa6244a774eca8bc4ab028212229a.shtml)

### 🌙 睡前放松｜提前半小时到一小时放下手机

睡前持续刷手机可能让大脑保持兴奋，拖延入睡。可以在准备睡觉前半小时到一小时停下来，听些舒缓音乐，让自己逐渐放松。

来源 · [烟台市心理康复医院](https://www.yantai.gov.cn/col/col67164/art/2026/art_1efacd5481db46829a7ecf2303605fd5.html)

### 🍲 微波加热｜带壳鸡蛋和密封包装别直接放进去

带壳鸡蛋、密闭包装食品内部受热后，蒸汽难以排出，可能胀裂或爆开。加热前先看说明书，选择适合微波炉的容器，并按要求留出排气口。

来源 · [国家市场监督管理总局](https://www.samr.gov.cn/spcjs/yjjl/art/2023/art_68faf9904c7446b0bb41449623e6f023.html)

### 🛗 电梯被困｜用警铃或对讲装置求助

保持镇静，用轿厢里的紧急报警装置联系值班人员，也可拨打张贴的维保救援电话。联系不上时拨打 119，留在轿厢内等待专业救援，避免扒门、爬出。

来源 · [北京市市场监督管理局、北京市消防救援局](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568251.html)

### 🚙 下车开门｜先看后视镜，再回头确认

车停稳后，开门前通过后视镜观察，并回头确认后方有没有骑车人或行人。用离车门较远的那只手开门，能帮助身体自然转向后方，驾驶人也应提醒乘客观察。

来源 · [深圳市龙岗区司法局](https://www.lg.gov.cn/bmzz/sfj/pftd/content/post_12960869.html)
