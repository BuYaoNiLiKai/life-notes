## 📅 今日知识 · 2026-10-12

### 01　🍲 饮食｜剩菜别在室温放太久

一般建议烹调后的剩菜在 **2 小时内冷藏**。大锅汤或炖菜可以先分装进浅盒，帮助更快降温。

**顺手做：** 吃不完就分装，及时放进冰箱。 · 来源：[FoodSafety.gov](https://www.foodsafety.gov/food-poisoning/bacteria-and-viruses)

### 02　🫧 健康｜洗手要顾到指缝和指尖

用肥皂覆盖手心、手背、指缝和指甲周围，揉搓至少 **20 秒**，再用流动水冲净。只搓手心，容易漏掉边角。

**顺手做：** 下次洗手时，别忘了拇指和指尖。 · 来源：[美国 CDC](https://www.cdc.gov/handwashing/)

### 03　👕 衣物护理｜普通衣物可以试试冷水洗

洗衣机的一部分能耗用来加热洗涤水；普通衣物用冷水通常也能洗净，往往更省电。油污或衣物标签有特别要求时，再选合适温度。

**顺手做：** 日常衣物选冷水档，先看洗涤标签。 · 来源：[ENERGY STAR](https://www.energystar.gov/products/clothes_washers)

### 04　🏠 居家｜开窗前看看室外空气

室外空气质量和天气合适时，开窗能增加新鲜空气交换；污染、花粉较多或天气极端时，减少开窗更合适。

**顺手做：** 开窗前看一眼空气质量和天气。 · 来源：[美国 EPA](https://www.epa.gov/indoor-air-quality-iaq/biological-contaminants-and-indoor-air-quality)

### 05　🚿 居家｜洗澡后让排风扇多转一会儿

淋浴时打开浴室排风扇，结束后再运行约 **15 分钟**，有助于排走湿气，减少浴室长期潮湿。

**顺手做：** 洗完澡先别急着关风扇。 · 来源：[ENERGY STAR](https://www.energystar.gov/products/recent_program_updates/low-no-cost-tips)

## 🌱 关于这个项目

「日常有知」是一份持续更新的生活知识小报。每期精选 5 条，尽量覆盖不同生活领域；每条都用简短的话说明 **是什么、为什么、能怎么做**，并附上可核对的来源。

## 🔄 每日更新

每天上午 **9:00（北京时间）** 更新一期：核对资料来源，将新内容追加到本 README 和网页数据中，再提交并推送到 GitHub。

## 🖥️ 网页预览

在项目根目录运行：

```powershell
python -m http.server 8000 --directory dist
```

然后打开 <http://localhost:8000>。
